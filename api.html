🚀 Ahmad Bhai Downloader API

Apni website ya bot mein hamara downloader lagane ke liye niche wala system use karein.

1. Aapki API Endpoint

https://ahmad-downloader.vercel.app/api/download?key=YOUR_KEY&url=VIDEO_URL

2. Copy-Paste Code (For Your Website)

Ye HTML/JS code apni site par lagayein:

<!-- User Side Downloader -->
<input type="text" id="vUrl" placeholder="Paste Video Link">
<button onclick="magicDownload()">Download Now</button>

<script>
function magicDownload() {
    const url = document.getElementById('vUrl').value;
    const apiKey = "GUEST_KEY_123"; // User ki apni key
    const apiUrl = `https://ahmad-downloader.vercel.app/api/download?key=${apiKey}&url=${encodeURIComponent(url)}`;
    
    window.location.href = apiUrl; // Direct download start ho jayega
}
</script>
