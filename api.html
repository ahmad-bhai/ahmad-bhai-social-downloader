Endpoint Documentation

Use the following link structure in your bots or websites:

https://ahmad-downloader.vercel.app/api/download?key=[YOUR_KEY]&url=[LINK]

Sample Javascript Fetch:

function downloadFile(targetUrl) {
  const myKey = localStorage.getItem('ahmad_api_key');
  const finalUrl = `https://your-site.vercel.app/api/download?key=${myKey}&url=${encodeURIComponent(targetUrl)}`;
  window.location.href = finalUrl;
}
